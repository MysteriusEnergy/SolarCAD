Rejilla `us_noaa_pvhpgn.tif` de NOAA, distribuida por [PROJ-data](https://github.com/OSGeo/PROJ-data) para la transformación NAD83/WGS84 de Puerto Rico e Islas Vírgenes. Recursos de PROJ-data bajo licencia abierta; consultar el repositorio de origen para condiciones y metadatos.

La aplicación usa este recurso localmente para convertir coordenadas sin conexión.
